# Circuito Cerrado

Sala de escape digital para **Educación Tecnológica, 3.º año del Ciclo Básico** (14–15 años).
Ocho estaciones sobre componentes electrónicos, simbología, circuitos, tecnología de control,
placa Arduino e inteligencia artificial. Se juega en unos 40 minutos desde cualquier navegador.

## Jugar

👉 **https://USUARIO.github.io/circuito-cerrado/**

(Reemplazá `USUARIO` por tu usuario de GitHub una vez publicado.)

## Cómo funciona

Cada estación resuelta entrega una palabra clave. Con la inicial de cada palabra, en el orden
en que se consiguieron, se arma el código que abre la puerta final.

| # | Estación | Contenido |
|---|----------|-----------|
| 01 | Taller de componentes | Reconocer componentes reales y su función |
| 02 | Panel de simbología | Símbolos normalizados e instrumentos de medición |
| 03 | Banco de circuitos | Serie y paralelo, circuito abierto y cerrado |
| 04 | Sala de control | Lazo abierto y cerrado, sensor, actuador |
| 05 | La placa del laboratorio | Partes de una placa Arduino Uno |
| 06 | El semáforo del pasillo | Cablear tres LEDs y completar el sketch |
| 07 | Alarma de proximidad | Cablear HC-SR04 y zumbador, lógica de distancias |
| 08 | Servidor de BIT-3 | IA generativa, tipos de IA y riesgos |

Las preguntas, las opciones y los tableros se sortean en cada partida. La casilla
**“Mezclar el orden de las estaciones”** de la pantalla de inicio hace que cada jugador
obtenga además un código de salida distinto.

## Características

- Un solo archivo HTML, sin dependencias ni instalación.
- Funciona sin conexión una vez cargado (solo las tipografías se bajan de Google Fonts).
- Se adapta a computadora, tablet y celular, en tema claro y oscuro.
- Guarda el avance en el navegador: si se corta la clase, se retoma donde iba.
- No pide registro ni recolecta ningún dato personal.
- Todas las ilustraciones son SVG originales escritos dentro del archivo.
